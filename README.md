# Robo-brainAn interactive Python-based AI program designed to converse with users, learn from their inputs, and store conversation data to remember past interactions over time.
Key Features:
Interactive Chat: Engages in real-time text-based conversations with users.
Learning Capability: Adapts and updates its responses dynamically based on new user inputs.
Memory System: Stores and recalls previous conversation history.
Tech Stack:
Language: Python
